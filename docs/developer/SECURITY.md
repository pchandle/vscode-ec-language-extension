# Security reporting

Do not report suspected security vulnerabilities through public GitHub issues, pull requests, discussions, or other public channels.

Report vulnerabilities privately to [au.security@aptissio.com](mailto:au.security@aptissio.com). Include, where safe to share:

- affected extension version and commit or tag;
- affected files and configuration;
- reproducible steps or a minimal proof of concept;
- observed and expected behaviour; and
- a description of the potential impact.

Do not include credentials, customer data, or private specification payloads unless they are necessary to demonstrate the issue and you have permission to share them.
